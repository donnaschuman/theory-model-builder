# Social Theory Model Builder

A single-page, offline web app that walks students from a theory + population + outcome to one plain-language research question, numbered hypotheses, and an editable path figure (solid and dashed lines).

- No build step: Netlify publishes `index.html` from the repo root.
- No data leaves the browser; work saves in the browser and via "Save my work" files.

## Optional settings

At the top of the first `<script>` in `index.html`: `GOATCOUNTER_CODE` (cookieless anonymous visit counts), `SURVEY_URL`, and `ADOPTION_URL`. Empty strings disable each.
